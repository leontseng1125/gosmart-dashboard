# 抓取完整歷史評論（Google Play）

## 這個腳本做什麼
`android-full-history.js` 會不斷往回翻頁抓 Google Play 的評論，
直到符合以下任一條件就停止：

1. 已經追溯到 3 年前的評論（可在檔案裡調整 `YEARS_BACK`）
2. Google Play 已經沒有更多分頁資料
3. 中途發生錯誤（例如被暫時封鎖）

抓到的完整清單會存成一個檔案：`data/android-full-history.json`，
跟每天排程產生的 `reviews-日期.json` 是分開的，不會互相覆蓋。

## 執行方式

```
node android-full-history.js
```

執行過程中，終端機會即時印出目前抓到第幾頁、累積幾則、追溯到哪一天了，
例如：

```
第 12 頁：抓到 150 則，累積 1800 則，最舊日期 2024-03-15
```

## 大概要跑多久？

- 每翻一頁之間會停頓 2 秒，避免請求太密集
- 假設總共有 2000 則評論、每頁 150 則，大約需要跑 13 頁 × 2 秒 ≈ 30 秒，
  但實際速度也取決於 Google 那邊的回應速度，可能更久
- 如果 app 的評論總數不多（例如幾百則），可能幾秒鐘就抓完 3 年份了

## 如果中途被暫時封鎖

如果看到抓取失敗的錯誤訊息，代表可能請求太密集了。可以：
- 把檔案裡的 `DELAY_MS` 從 2000（2秒）調大，例如改成 5000（5秒）
- 稍等幾分鐘後重新執行

## 關於 iOS

App Store 目前沒有對應的完整歷史抓取方式（詳見主要對話中的說明），
所以這支腳本只涵蓋 Google Play。iOS 那邊維持用 `appstore-playwright.js`
抓取網頁上目前顯示的近期評論。
